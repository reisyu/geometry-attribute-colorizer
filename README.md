# Geometry Attribute Colorizer

石垣などの3D輪郭データを読み込んで、石材ごとの寸法を計算し、色分けして表示するツールです。現場での所見の記録にも使えます。
ブラウザだけで動き、インストールは不要です。読み込んだファイルがサーバーに送られることもありません。

## 主な機能

- 寸法の計算: DXFを読み込むと、幅・高さ・面積・傾斜角などを石ごとに計算します。
  事前の準備はいりません。
- 色分けと図の書き出し: 属性ごとに色分けし、報告書に使えるベクター図（SVG）として書き出せます。
  図には分布のヒストグラムとスケールバーが付きます。
- 現場での記録: タブレットで所見を入力できます。次の点検では前回の記録を見ながら書き足せます。
  記録した石は色が変わるので、どこまで確認したかを図で確かめられます。

## 試してみる

1. 上のリンクを開きます（大阪城石垣のサンプルが表示されます）。
2. 「3. 色分けする」で属性を切り替えてみます（幅、高さ、面積、傾斜角など）。
3. 石をタップし、「調査」タブのメモ欄に何か入力すると、その石の色が変わります。
4. 「7. 書き出す」の「点検データをZIPで保存」で、記録ごと保存できます。

読み込んだファイルはサーバーに送信されず、すべてブラウザの中で処理されます。

## 石垣BIMワークフローとの関係

奈良文化財研究所の[石垣BIMプロジェクト](https://www.nabunken.go.jp/research/stonewallbim.html)が公開している「石垣AIセグメンター」（試験版）の出力DXFを、変換せずにそのまま読み込めます。
セグメンターは石垣の面から石材を1つずつ識別し、それぞれをポリゴンにした3D DXFを出力します。このアプリはその形式を想定して作っています。

```
3D計測(フォトグラメトリ)        Metashape 等
    ↓
AIによる自動セグメンテーション    石垣AIセグメンター(試験版)
    ↓  1石ずつポリゴン化した3D DXF
属性の計算・色分け・記録・図化    ← このアプリ(ブラウザのみ)
```

専用ソフトを入れなくても、ブラウザだけで寸法の計算、属性による色分け、所見の記録、立面図SVGの書き出しまでできます。
タブレットでも動くので、現場に持ち出して使えます。

### 読み込みと属性計算

- DXF（閉じたポリライン）を読み込み、属性を自動で計算します。
  - LWPOLYLINEとPOLYLINEの両方に対応しています。AutoCAD・QGIS・Illustratorなどが書き出す一般的なDXFも、クラスタリングソフトやRhinoの出力も読み込めます。
  - 輪郭は最適フィット平面に投影して計算するので、完全な平面でなくても構いません。
  - 最小外接矩形は回転キャリパー法で厳密に求めます。
  - 1万輪郭程度の大きなデータも、進捗を表示しながら処理します。
  - 平面直角座標系のような大きな座標値は、表示精度を保つために自動で原点付近へ移動します。
- GLB（glTF 2.0バイナリ）を3D表示し、回転・パン・ズームで確認できます。
- CSVのID列とオブジェクト名を照合して、CSVの属性を各オブジェクトに割り当てます。
- フォトグラメトリモデル（OBJ、MTL、テクスチャ画像）を読み込み、輪郭と色分けを重ねて表示できます。
  輪郭モデルは常に写真より手前に描かれます。輪郭モデルの不透明度（既定は65%）を下げると、下の写真が透けて見えます。
  フォルダごと選択すると必要なファイルがまとめて読み込まれます。
  テクスチャは最大2048pxに自動で縮小するので、大きなデータでも安定して動きます。
- DXFの読み込み時に、立面図で左下のオブジェクトから順に1、2、3…とIDを振り直します（下の段から順に、同じ段の中では左から右へ）。
  元のIDはSrcID属性に残るので、元データと照合できます。
  段（コース）の番号もCourse属性に入るので、段ごとの色分けや絞り込みに使えます。

### 色分け

- 属性の値で色分けします。数値の属性はグラデーション、文字の属性はカテゴリごとの色になります（自動で判定します）。
- 配色は「赤→青」「赤→緑」「黄→青」「グレースケール」「カスタム」から選べます。カスタムでは3色のグラデーションも作れます。
- 文字の属性は、見分けやすい20色を使い、足りない分は自動で色を作るので、種類がいくつあっても色分けできます。
  「上位7カテゴリのみ色分け（残りはその他）」をオンにすると、種類の多い属性も見やすくなります。
- 傾きライン: 各オブジェクトの外接矩形の水平軸に沿って中心線を描きます。
  線の色は矩形回転角で変わり（0°が青、±45°が赤。変更できます）、太さは実寸で20〜100mmの範囲で指定できます。
  線が水平にそろっていれば整った積み方、ばらついていれば乱積みに近いと読み取れます。
- チェックを1つ入れるだけで、グラデーションの向きを反転できます。
- グラデーションの最小値と最大値を手で決められます。外れ値の影響を抑えたいときや、複数のモデルで基準をそろえたいときに使います。
  指定した範囲は属性ごとに記憶されるので、別の属性に切り替えてから戻っても設定は残ります。
  この設定は既定でオンです。誰が開いても同じ配色になり、書き出した図を並べて比べられます。
  データに合わせて範囲を決めたい場合はチェックを外してください。
- よく使う属性には範囲の初期値を入れてあります（幅・高さ 0.1〜1.5、面積 0.05〜1、矩形充填率 0.5〜0.9、アスペクト比 0.25〜4、傾斜角 30〜90、矩形回転角 -45〜45）。
  いつも同じ基準で色が付くので、別の壁面と比べるときも色の意味が変わりません。
  データが初期値から大きく外れて範囲が成り立たないときは、どうするかを確認するダイアログが出ます。設定が勝手に変わることはありません。
- 一度色分けを実行した後は、配色や範囲の変更がすぐに反映されます。
- 凡例には、グラデーションバーの上に分布のヒストグラムが付きます。
  ヒストグラムの各ビンは色分けと同じ色で塗られるので、どの色の石がいくつあるかがわかります。
- 数値の属性ごとに残す範囲を決めて、表示するオブジェクトを絞り込めます（範囲は複数指定できます）。
  自己交差の大きさで除外することもできます。除外した石は半透明にするか、非表示にします。
  色分けをしていなくても使えるので、形だけで絞り込んで見たいときにも使えます。
- 調査でよく使う3つの条件（面積0.05以上、アスペクト比0.25〜4、傾斜角30以上）を、ボタン1つでまとめて適用できます。
  小さすぎる破片、極端に細長い形、水平に近い面が除かれます。

### 現場での記録（メモ・分類）

- オブジェクトを選ぶと、属性インスペクタにメモ欄が出ます。点検の所見などを書いておくと、CSVの `Note` 列として書き出されます。
  メモは計算で作り直せないデータなので、ほかの属性とは扱いを分けています。
- 記録した石は、その場で色が変わります。点検データを開くと `履歴:記録の状況` で色分けした状態で始まり、メモを書いた石から色が変わっていきます。
  色の意味は、赤が「前回の指摘があり、今回まだ書いていない」、青が「前回の指摘を見て今回書いた」、橙が「今回新しく書いた」、グレーが「記録なし」です。
  赤がなくなれば、前回指摘された石はすべて確認したことになります。
  初回の点検では橙とグレーの2色だけです。
  メモの本文はラベルにも表示できます（長いものは先頭だけ表示します）。
- 保存していない記録があることは、ビュー左上のバッジ、ステップ7の見出しの件数、CSV保存ボタンの強調の3か所で知らせます。
  この表示は書き出すまで消えません。保存せずに閉じようとすると確認が出ます。
- 書いたメモはブラウザに自動で控えておき、同じデータを読み込み直したときに復元するかどうかを尋ねます。
  ただし、この控えは同じブラウザの中だけの一時的なものです。確実に残すにはCSVで保存してください。
- 保存したメモを読み込み直すときは、元のID（`SrcID`）で照合します。DXFを作り直すと画面上のIDは振り直されますが、メモは元のオブジェクトに付いたままです。
  IDがずれていた場合は、そのことを知らせます。
- 石種やエリアのように、計算では出せない分類を手で付けられます。
  ステップ2で分類の列を作り、オブジェクトを選んでビュー上のパネルから値を付けます。
  選択肢をあらかじめ決めておく必要はありません。その列で使われている値がそのまま候補になり、新しい値を入力するとすぐ候補に加わります。
  使った値はCSVに保存されるので、前回のCSVを読み込めば候補も戻ります。表記の揺れは後からまとめられます。
  まだ値を付けていないオブジェクトは灰色で表示されるので、付け忘れを見つけやすくなっています。
- 分類もメモと同じく計算では作り直せないデータなので、未保存の警告と自動の控えの対象になっています。
- 前回までの記録を参考として表示できます。前回の調査で書き出したCSVを読み込むと「前回:」で始まる列が追加され、石を選ぶとメモ欄の上に前回の記述が表示されます。
  「履歴:記録の状況」で色分けすると前回メモのある石が赤くなるので、今回確認すべき石が図でわかります。
  今回書くと青に変わるので、どこまで確認したかも同じ図で追えます。
  前回の記録は編集できず、書き出すCSVにも含まれません（記録として残すのは今回の分だけです）。
  前回と今回でIDが同じであることが前提なので、一度「ID付きGLB」を書き出し、以後はそれを台紙として使ってください。
- 点検データはZIPファイル1つにまとめて持ち運べます。モデル・属性・記録を一緒に保存するので、次の点検ではそのZIPを開くだけです。
  同じ日に開き直しても書いた内容は残り、日付が変わると前の回が自動的に「前回」になります。
  記録は「1オブジェクト・1調査日・1調査者で1行」という形で持っているので、複数人のZIPから記録CSVを集めて1つのZIPに入れれば、開くだけで統合されます。
  同じ石に2人が書いた場合は両方残ります。記録に入るのは、何か書いた石だけです。
- 属性パネルは「属性」タブと「調査」タブに分かれています。現場で使う調査タブには、調査日・調査者・分類・過去の記述・メモ欄をまとめました。
  前回最後に開いていたタブが次も開くので、現場と事務所でそれぞれ使いやすい状態が保たれます。
- 記録がたまってくると、`履歴:記録回数` や `履歴:最終記録日` で色分けできるようになります。
  一度も記録のない石はグレーになるので、記録のある石だけに色が付きます。
  何度も指摘されている石を見つけるなど、前回の記録だけではわからない経年の変化を追えます。
- 複数人の記録を統合した後、`履歴:調査者` で色分けすると、分担どおりに確認できたかを図で確かめられます。
  同じ石に2人が書いていれば「佐藤・山田」のように並べて表示します。

### 表示・確認

- オブジェクトをクリック（タップ）すると、属性の一覧を表示します。
  選択中のオブジェクトはオレンジの輪郭で強調されます。輪郭の太さは画面上で3pxに固定しているので、ズームしても変わりません。
- 位置情報モード: ビュー右上の「現在地」でオン・オフを切り替えます。
  オンの間は俯瞰図が表示され、歩くとマーカーが付いてきます。
  平面直角座標系は自動で判定します（19の系と軸の並びの組み合わせから選びます）。
  位置には必ず精度円を一緒に描くので、誤差の大きさが見てわかります。
  GPSの誤差は現地で20〜50mあるため、個々の石の特定には使えません。
  座標系を判定できないときは何も表示しません。位置は外部に送信せず、CSVにも記録しません。
  視点が勝手に動くことはなく、「近くの区画を見る」を押したときだけ移動します。
  オフにすると、電池を節約するために測位を止めます。
  オンラインで開いたときだけ使えます（オフライン版ではブラウザが位置情報の利用を許可しないため）。
- 位置情報モードでは、いま画面に映っている石が俯瞰図の上で強調されます。
  自分が立っている場所と、編集しようとしている場所がずれていないかを確かめるためのものです。
  誤差が20mあると隣の区画を見ていることがあり、気づかないまま分類やメモを書き込んでしまうのを防ぎます。
- 選択モードで画面をなぞると、複数のオブジェクトをまとめて選べます（ブラシ選択）。
  「はらみ出している一角」のように数値では絞り込めない範囲を選び、メモや分類をまとめて付けるときに使います。
  選んでいないオブジェクトは薄く表示されるので、選んだ範囲がわかりやすくなります。取り消しは1回なぞるごとにできます。
- 「正面」（立面図SVGと同じ向き）、「上面」、「全体」のボタンで、視点をすぐに切り替えられます。
- 透視投影（既定）と平行投影をボタン1つで切り替えられます。
  向きとズームは切り替えても変わりません。「現在のビューをSVGで保存」の書き出しにも反映されます。
- ビューの右下に、元データのX・Y・Z軸がいまどちらを向いているかを示す軸ギズモを表示します。
  平行投影のときは、そのことをラベルでも表示します。
- ビュー右上のボタンで、ダークテーマとライトテーマを切り替えられます（投影や印刷に合わせて使えます）。
- ビュー右上の「文字」で、文字の大きさを「標準」「大」「特大」から選べます。
  文字に合わせてパネルの幅も広がり、次に開いたときも設定が残ります。
  タブレットで文字が読みにくいという意見を受けて追加しました。
  ブラウザのピンチ操作で拡大したままビューを操作すると、画面全体は大きいのにビューだけが小さくなってしまうため、こちらを使ってください。
- 各オブジェクトの位置に、IDや属性の値をラベルとして表示できます。
  複数の属性を同時に表示したり、文字の大きさを変えたりできます。遠くのラベルは自動で非表示になります。

### 書き出し

- 「データ名」を設定しておくと、`本丸東面_2026調査_elevation.svg` のように書き出すファイル名の先頭に付きます。
  複数の壁面を扱っても、ダウンロードフォルダの中で区別できます。
- 自動計算した属性（または読み込んだ属性）をCSVとして保存できます。
  「データ名」を設定しておくと全行にDataset列が付くので、複数の調査データをBIツールやPython（pandas）で結合したときに、どのデータから来た行かを区別できます。
- オブジェクト名（ID）を保持したGLBを書き出せます。
  法線の向きは壁全体で自動的にそろえます。
  BlenderやRhinoなどほかのツールで再利用でき、DXFからGLBへの変換にも使えます。
- 点検データ（ZIP）からもSVGを書き出せます。現場で記録した状態から、DXFを読み直さずに報告書用の図を作れます。
  DXFを読み直すとIDが振り直され、それまでの記録との対応が切れてしまうので注意してください。
- 立面図SVG: モデルを正面から平行投影で見た立面図を、ベクター形式のSVGとして書き出します。
  凡例・スケールバー・ラベル・傾きラインを入れるかどうかを選べます。輪郭線の太さ（実寸mm）の指定や、塗りつぶしなしの線画にもできます。
  Illustratorなどで後から編集できます。
- 現在のビューのSVG: 立面図とは別に、いまのカメラの向きとズームのままSVGを書き出します。
  透視投影ならパースが付き、平行投影ならパースなしで出力されます。
  凡例・ラベル・傾きラインの設定は立面図と共通です。縮尺が一定とは限らないので、スケールバーは付けられません。
- 属性ごとの立面図SVGをまとめて書き出し、1つのZIPにして保存できます。チェックを入れた属性の分だけ作成します。
  色分けをしない「傾きラインの線画」も入れられます。
  どの図も向きと縮尺がそろうので、報告書で並べて比べられます。
  ZIPは外部ライブラリを使わず、ブラウザ標準の圧縮機能で作っています。
- iPadやスマートフォンなど指で操作する端末では、書き出しボタンが「〜で送る」に変わり、押すと共有シートが開きます。
  メール、チャット、AirDropでその場で渡せるので、ファイルアプリから探し出す必要はありません。
  共有シートの「ファイルに保存」を選べば、端末に保存することもできます。
  送らずに閉じた場合、メモと分類が未保存であるという表示は消えません。
  まとめてZIPを作る機能だけは、作成に数秒かかるため「作る」と「送る」の2回に分けて押します。
  パソコンではこれまでどおり、ファイルとしてダウンロードされます。

## 自動計算される属性（DXF読み込み時）

| 属性名 | 日本語名 | 内容 |
|---|---|---|
| Width | 幅 | 最小外接矩形の2辺のうち、水平に近いほうの辺の長さ |
| Height | 高さ | 最小外接矩形の2辺のうち、鉛直に近いほうの辺の長さ |
| Area | 面積 | フィット平面に投影した輪郭の面積 |
| FillRate | 矩形充填率 | 輪郭の面積を外接矩形の面積で割った値。1に近いほど矩形に近い |
| Aspect | アスペクト比 | 幅を高さで割った値。1より大きいほど横長、小さいほど縦長で、1に近いほど正方形に近い |
| Tilt | 傾斜角 | 面の法線と鉛直（+Z）のなす角。0°は水平な面、90°は垂直な面 |
| RectAngle | 矩形回転角 | 外接矩形の水平辺が、面内の水平方向から何度回転しているか。反時計回り（右上がり）が正で、範囲は±45° |
| Flatness | 平面性 | フィット平面からの最大のずれ。大きいほど平面として扱った計算の信頼性が下がる |
| SelfIntersect | 自己交差 | 輪郭の自己交差の大きさ（0〜0.5）。0なら交差なし。Areaはこの値の2倍だけ小さく出る |
| Note | メモ | 画面で入力した所見。入力したときだけ列が追加される |
| HasNote | メモの有無 | メモがあれば「あり」、なければ「なし」。メモの本文から自動で作られる |
| X / Y / Z | 重心座標 | 輪郭の重心の座標（原点を移動する前の元の値）。Zで色分けすると標高がわかる |
| SrcID | 元ID | 読み込み時にレイヤー名から取ったID（振り直す前の値） |
| Course | 段 | 立面図で下から数えた段（コース）の番号 |

アプリでは `Width(幅)` のように英語名と日本語名を並べて表示し、属性を選ぶとその定義が表示されます。

## 使い方

### DXFから始める場合（属性を自動計算する）

1. DXFファイルをビューポートにドラッグ＆ドロップします（パネルから選んでも構いません）。
2. 属性が自動で計算され、色分けされた状態で表示されます。手順2のCSV読み込みは不要です。
3. 「3. 色分けする」で、対象の属性・配色・範囲を調整します。変更はすぐに反映されます。
4. 「7. 書き出す」から、CSV、ID付きGLB、SVGとして保存できます。

### フォトグラメトリモデルを重ねる場合

1. 先にDXFを読み込みます。原点の移動量がここで決まるので、写真モデルと位置がそろいます。
2. 「フォトグラメトリモデルを重ねる」から、.obj・.mtl・テクスチャ画像をすべてまとめて選びます。ビューポートにまとめてドロップしても構いません。
3. 読み込んだら、「輪郭モデルの不透明度」のスライダーで写真の透け具合を調整します。輪郭モデルは常に写真より手前に描かれます。
4. 写真モデルは表示のためだけのもので、クリックでの選択、色分け、書き出しの対象にはなりません。

### GLBとCSVから始める場合

1. GLBファイルをビューポートにドラッグ＆ドロップします。
2. CSVファイルを読み込み、ID列を確認します。
3. 属性と配色を選んで、色分けを実行します。

### ビューポートの操作

| 操作 | 動作 |
|---|---|
| 左ドラッグ / 1本指ドラッグ | 回転（画面の中央に見えているものを中心に回ります） |
| 右ドラッグ / Shift+ドラッグ / 2本指ドラッグ | パン（平行移動） |
| ホイール / 2本指ピンチ | ズーム（マウスカーソルの位置を中心に拡大・縮小します） |
| クリック / タップ | オブジェクトの属性を表示 |
| ダブルクリック / ダブルタップ | その位置を回転の中心にする |

iPadなどのタッチ操作の端末でも使えます。

左のパネルは、3D表示の左端にあるつまみで閉じられます。読み込みと色分けを終えて現場で作業するときは、3D表示を広くしたほうが見やすくなります。iPadを縦にした場合、表示の幅は468pxから768pxに広がります。
パネルを閉じている間、アプリからのお知らせは画面の左上に表示されます。

ビュー右上の「選択」で選択モードに切り替えると（Escで解除）、左ドラッグ（1本指）がなぞって複数を選ぶブラシになります。
パンとズームは通常どおり使えますが、回転は通常モードでしかできません。
選択モードを抜けると選択が解除されるので、値やメモは抜ける前に付けてください。

### 色分けのコツ

- RectAngle（矩形回転角）の範囲は、初期値で -45〜+45 に設定してあります。
  さらにカスタム配色で赤・白・青の3色（「中間色を使う」をオン）にすると、左に傾いた石が赤、水平な石が白、右に傾いた石が青になり、見た目で判断しやすくなります。
- 外れ値のせいで色の差が出にくいときは、「範囲を手動で指定」で範囲を狭めてください。

## データの準備

### DXFファイル（石垣の輪郭など）

- 閉じたポリラインで作られている必要があります。次の形式に対応しています。
  - LWPOLYLINE: AutoCAD・QGIS・Illustratorなど、一般的なCADやGISのツールが標準で書き出す形式です。標高（elevation）はZ座標として読み込みます。
  - POLYLINE / VERTEX: 閉じた3Dポリラインです（クラスタリングソフトの出力形式）。Rhinoなどが書き出す2Dポリラインにも対応しています。
  - 傾いた座標系（OCS）で書かれたものは、自動でワールド座標に変換します。
  - 円弧（バルジ）を含むポリラインは、円弧の部分を直線として読み込みます。該当する件数は読み込み時に表示します。
- 線分（LINE）、スプライン（SPLINE）、円だけでできたファイルは読み込めません。CADでポリラインに変換してから書き出してください。
- 1つの輪郭を1つのオブジェクトとして扱います。
- レイヤー名の末尾の数字がIDになります（例: `Layer123` ならIDは `123`）。
- 輪郭は完全な平面でなくても構いません（最適フィット平面に投影して計算します）。
- Z軸が鉛直上向き、XY平面が水平であるものとして、幅・高さ・傾斜角・回転角を求めます。

### OBJファイル（フォトグラメトリモデル）

- .obj・.mtl・テクスチャ画像（PNG/JPG）を同時にまとめて選んでください。MTLの中のテクスチャ指定は、ファイル名で自動的に対応づけます。
- 座標系はDXFと同じ（Z軸が鉛直で、平面直角座標系などの実座標）であることを前提としています。
- テクスチャは読み込み時に最大2048pxまで自動で縮小します。

### GLBファイル

- glTF 2.0のバイナリ形式（.glb）に対応しています。.gltfと.binに分かれた形式には対応していません。
- オブジェクト名がCSVのIDと一致している必要があります。
  - `Cell_1` のように接頭辞が付いている場合は、「オブジェクト名の接頭辞」欄にその接頭辞を入力してください。

### CSVファイル

- 1行目は見出し（列名）にし、ID列と任意の数の属性列を並べます。
- 属性は数値でも文字でも構いません（自動で判定します）。

```csv
ID,Area,Width,Height
1,0.113581,0.52,0.31
2,0.246072,0.68,0.45
```

## 想定している使い方（石垣調査の例）

1. 石垣をフォトグラメトリで3Dモデルにします。
2. クラスタリングで石ごとの輪郭を取り出し、DXFとして書き出します。
3. このアプリでDXFを読み込みます。各石の幅・高さ・面積・矩形充填率・傾斜角・矩形回転角が自動で計算され、属性に応じて色分けされます。
4. 現場での所見や、石種・エリアなどの分類を、ブラシで選んでまとめて入力します。
5. 必要に応じてCSVやID付きGLBで書き出し、ほかのツールで分析や再利用をします。
   手で入力した内容もCSVに入るので、次回そのCSVを読み込めば元に戻せます。

## 設定の保存

見た目に関する設定は、次に開いたときにも引き継がれます。たとえば、背景モデルと輪郭モデルの不透明度、傾きラインの色と太さ、ラベルの文字の大きさ、SVGに入れる要素、ライト/ダークの切り替え、投影方式などです。

一方、色分けの設定（配色・範囲・反転）は引き継ぎません。誰が開いても同じ配色になるようにするためです。

設定はそのブラウザの中にだけ保存され、外部には送信されません。

## 使う前に知っておいてほしいこと

このアプリは測量機器ではありません。計算結果は読み込んだデータから求めたものなので、元の3Dモデルより精度が高くなることはありません。

具体的には、次のような限界があります。

- 現在地の表示では、石を特定することはできません。GPSの誤差は現地で20〜50mあります。
  そのため位置を点だけで示さず、必ず精度円を一緒に描いています。円が壁の半分を覆っていれば、実際にそれだけの誤差があるということです。
  座標系を判定できないときは、推測で位置を出さずに理由を表示します。
- 自己交差のある輪郭は、面積が実際より小さく出ます。交差の大きさは `SelfIntersect` として出力しているので、この値がある石の面積はそのまま信用しないでください（面積はこの値の2倍だけ小さくなります）。
- 平面性（`Flatness`）の値が大きい石は、計算結果の信頼性が下がります。幅・高さ・面積は、最適フィット平面に投影して求めているためです。
- 円弧（バルジ）を含むポリラインは、円弧を直線として読み込むので、形が少し変わります（該当する件数は読み込み時に表示します）。
- 入力したメモと分類は、保存しないと残りません。ブラウザへの自動の控えは一時的なものなので、点検データ（ZIP）かCSVで保存してください。
